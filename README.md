# VEQTA

**VEQTA — открытая русскоязычная экосистема для изучения Frappe Framework и создания решений на его основе.**

Проект объединяет инженерные материалы, практическое обучение, эксперименты и будущие open-source продукты.

VEQTA строится на Frappe Framework, не заменяет его и не является официальным проектом Frappe Technologies.

## Что есть в репозитории

### Frappe

В разделе [`frappe/`](frappe/README.md) находятся два основных направления:

- **VEQTA Engineering** — [архитектурный стандарт Frappe](frappe/frappe-architecture-standard/README.md);
- **VEQTA Learn** — [практикумы по разработке на Frappe Framework](frappe/frappe-training/README.md).

### Labs

В [`labs/`](labs/README.md) публикуются воспроизводимые исследования Frappe: постановка технического вопроса, реализация на живом `App` и `Site`, наблюдаемый результат и инженерный вывод.

### Products

Готовых продуктов VEQTA пока нет. Когда эксперимент вырастает в самостоятельный продукт, его исходный код развивается в отдельном репозитории. Основой продукта на Frappe обычно является собственный `App`; дополнительные компоненты появляются только тогда, когда их требует задача.

## Подход

Frappe уже содержит большую часть механизмов, необходимых прикладной системе: `DocType`, `Document`, permissions, `Workflow`, фоновые задачи, API, Desk и точки расширения.

VEQTA рассматривает эти возможности как основу архитектуры и добавляет собственный код там, где этого требует конкретная задача.

## Язык

Основной язык VEQTA — русский. Официальные термины Frappe, код, команды и API сохраняются в исходной форме там, где это важно для точности: `DocType`, `Document`, `Workflow`, `App`, `Site`, `Bench` и другие.
