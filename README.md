# VEQTA

VEQTA — open-source приложение на **Frappe Framework** для управления работой через настраиваемые процессы и общую структурированную модель данных.

> **Frappe даёт инструменты. VEQTA даёт модель работы. Пользователь задаёт процесс.**

## Статус

Стадия проекта: **prototype v0.1**.

Первый стенд должен превратить этот repository в реальный Frappe app `veqta`. До результатов prototype модель v0.1 не считается стабильным контрактом.

## Принципы

- использовать штатные возможности Frappe, если они решают задачу корректно;
- не привязывать VEQTA к одной методологии управления работой;
- один бизнес-факт хранить в одном месте;
- ключевые данные хранить структурированно;
- производные показатели вычислять из первичных данных;
- согласованное состояние продукта должно воспроизводиться из Git.

## Модель v0.1

Проверяются:

- `Work Item` — единица управляемой работы;
- `Work Type` — тип работы;
- State — через штатный Frappe Workflow / Workflow State.

Assignment, история состояний и Kanban сначала проверяются штатными механизмами Frappe.
