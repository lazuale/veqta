# VEQTA

**VEQTA — открытая русскоязычная экосистема для изучения Frappe Framework и создания приложений на его основе.**

Проект объединяет инженерные материалы, практическое обучение, экспериментальные реализации и будущие open-source продукты.

VEQTA строится на Frappe Framework, не заменяет его и не является официальным проектом Frappe Technologies.

## Направления

### VEQTA Engineering

Архитектурные материалы о том, как проектировать приложения в логике самого Frappe: где использовать штатные механизмы Framework, где проходят границы собственного кода и чем подтверждается принятое решение.

Сейчас в этом направлении развивается [архитектурный стандарт Frappe](docs/frappe-architecture-standard/README.md).

### VEQTA Learn

Практические учебные материалы и курсы по разработке на Frappe. Обучение строится вокруг законченных задач и архитектурных решений, а не вокруг последовательного обзора функций Framework.

Текущий учебный контур находится в [`docs/frappe-training/`](docs/frappe-training/).

### VEQTA Labs

Эксперименты и прототипы для проверки спорных решений на живом Frappe `App` и `Site`.

Текущий прототип управления рабочими единицами рассматривается как экспериментальное направление Work Management, а не как определение всей VEQTA.

### VEQTA Products

Самостоятельные приложения на Frappe для реального использования. Каждый будущий продукт получает собственную предметную область, документацию и жизненный цикл.

## Подход

Frappe уже содержит большую часть механизмов, необходимых прикладной системе: `DocType`, `Document`, permissions, `Workflow`, фоновые задачи, API, Desk и точки расширения.

Поэтому VEQTA начинает проектирование с понимания возможностей Framework и добавляет собственную архитектуру там, где этого действительно требует задача.

## Язык

Основной язык VEQTA — русский. Официальные термины Frappe, код, команды и API сохраняются в исходной форме там, где это важно для точности: `DocType`, `Document`, `Workflow`, `App`, `Site`, `Bench` и другие.
