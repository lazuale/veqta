# VEQTA

VEQTA — проект приложения на **Frappe Framework** для управления работой через настраиваемые пользователем процессы и общую структурированную модель данных.

> **Frappe даёт инструменты. VEQTA даёт модель работы. Пользователь задаёт процесс.**

## Статус

Сейчас проект находится на стадии **prototype v0.1**.

Репозиторий подготовлен как рабочее пространство проекта. Исполняемый Frappe app scaffold будет добавлен первым коммитом с локального dev-стенда; после этого этот же repository является непосредственным исходным кодом приложения `veqta`.

До завершения prototype состав Core не считается замороженным.

## Основная идея

VEQTA не должна становиться framework поверх Frappe, ERP/CRM/BPM-комбайном или отдельным no-code конструктором.

Принципы:

- Frappe остаётся технической платформой;
- VEQTA добавляет только собственную модель управляемой работы;
- процесс по возможности настраивается штатными средствами Frappe;
- один бизнес-факт имеет один источник истины;
- данные должны оставаться структурированными и пригодными для аналитики;
- новая сущность или подсистема появляется только после доказанной необходимости;
- согласованная конфигурация со стенда должна быть воспроизводима из Git.

## Текущая модель v0.1

Проверяются три базовых понятия:

- `Work Item` — единица управляемой работы;
- `Work Type` — тип/классификация работы;
- State — текущее состояние, в prototype сначала через штатный Frappe Workflow.

Assignment, история состояний и Kanban сначала проверяются штатными primitives Frappe. Собственные механизмы не создаются заранее.

## Источник истины

`lazuale/veqta` — источник истины продукта.

Изменение, которое существует только в локальной базе dev-site и не представлено исходниками или штатно экспортированной конфигурацией приложения, не считается частью VEQTA.

Контрольный критерий:

```text
чистый совместимый Frappe site
+ repository VEQTA
+ install-app / migrate
= согласованное состояние продукта
```

## Frappe baseline

Все технические решения сверяются с **актуальной stable-линией Frappe**, официальной документацией и официальными исходниками `frappe/frappe`.

На дату последней проверки — 2026-08-29 — рабочая линия prototype: `version-16`, последняя проверенная stable-версия: `v16.32.0`.

Подробно: [DEVELOPMENT.md](docs/DEVELOPMENT.md).
