# Проекты практикума

Проекты выполняются по порядку. Для работы использовать LABS, а README проекта — как
архитектурную спецификацию:

1. [Реестр оборудования](01-equipment-register/LABS.md) — данные и метаданные.
2. [Заявки на закупку](02-purchase-requests/LABS.md) — документ и процесс.
3. [Внешняя приёмная](03-service-intake/LABS.md) — граница доверия и web-контур.

Каждый проект создаёт собственный app и site. Переиспользуется Frappe Bench и приобретённые навыки, но не DocType и рабочие данные предыдущего продукта.
