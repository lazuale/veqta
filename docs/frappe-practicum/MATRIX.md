# Матрица практикумов

Матрица отвечает на два вопроса:

1. где ученик впервые встречает конкретный механизм Frappe;
2. не осталось ли базовых возможностей, которые мы просто забыли.

Обозначения:

- `●` — изучается впервые и обязательно;
- `○` — используется повторно;
- `△` — дополнительное упражнение;
- `—` — в проекте не требуется.

## Что сознательно не требуется от базовых проектов

Эти механизмы не вычёркиваются из Frappe, но не являются условием завершения программы:

- собственный Python controller;
- hooks;
- собственный JavaScript;
- Client Script;
- Server Script;
- REST API;
- Webhooks;
- Query Report;
- Script Report;
- Jinja-шаблоны;
- custom Website/Portal pages;
- Virtual DocType;
- внешние библиотеки.

Они добавляются в следующие практикумы только тогда, когда появляется задача, которую штатная конфигурация уже не решает.

## Контроль полноты

Перед публикацией каждого проекта проверяем:

1. механизм действительно существует в актуальной ветке `version-16`;
2. в уроке используется его реальное название и текущее поведение;
3. шаг воспроизводится на чистом учебном стенде;
4. новая функция решает задачу проекта, а не вставлена ради покрытия;
5. матрица обновлена, если актуальный v16 добавил или изменил важную базовую возможность.
