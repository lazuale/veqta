# Матрица практикумов

Статус: **контроль покрытия базового уровня**  
Платформа: **Frappe Framework 16**

## 1. Обозначения

В таблицах используются обозначения:

- `●` — механизм изучается впервые и является частью обязательной практики;
- `○` — механизм повторно используется и закрепляется;
- `△` — дополнительное упражнение, не влияет на прохождение базового курса;
- `—` — механизм не является частью проекта.

Матрица нужна для двух задач:

1. не пропустить важный базовый механизм;
2. не перегрузить один проект большим количеством новых тем.

## 12. Обязательные контрольные сценарии

| Проект | Минимальный контроль |
|---|---|
| P0 | site открывается; Administrator входит; тестовые пользователи созданы; Desk доступен |
| P1 | импортировать данные; создать объект вручную; оформить передачу; найти данные фильтрами; экспортировать выборку |
| P2 | заявитель создаёт; координатор видит; исполнитель получает назначение; пользователь без права не получает лишний доступ |
| P3 | провести одну заявку до согласования; одну отклонить; один submitted-документ отменить; проверить роли переходов |
| P4 | создать несколько проверок; открыть календарь; получить агрегированный отчёт; вывести показатель/диаграмму; распечатать документ |

## 14. Правило изменения матрицы

Матрица является контрольным документом курса.

Любое добавление новой обязательной возможности должно отвечать на три вопроса:

1. В каком проекте она изучается впервые?
2. Какую реальную задачу этого проекта она решает?
3. Почему её нельзя оставить на следующем уровне?

Если на эти вопросы нет ясного ответа, возможность не включается в обязательную базу.
