# Лабораторная 39. Web Form

## Цель

Создать внешний web-интерфейс над `Request` и увидеть его границу относительно Desk.

## Сделай руками

Создай Web Form для `Request`.

Выведи поля:

```text
Subject
Description
Priority
Due Date
Area
```

Не выводи `Internal Cost`.

Настрой route, например:

```text
training-request
```

## Проверь как authenticated user

Открой URL Web Form, создай Request и затем найди его в Desk.

## Guest

Если сценарий главы позволяет Guest creation, временно включи соответствующую настройку и создай отдельный тестовый Request как Guest. Затем проверь owner/permissions/данные в Desk.

Не оставляй публичное создание включённым без понимания последствий.

## Эксперимент

Убери поле `Priority` из Web Form, но оставь его в DocType. Создай запись и посмотри default/пустое значение. Это показывает, что Web Form — выбранная поверхность над DocType, а не копия всей Form View.

## Намеренная ошибка

Попробуй передать через запрос поле, которого нет в Web Form. Проверь, что v16 ограничивает набор данных формой/валидацией. Не пытайся обходить security — цель увидеть boundary.

## Проверка себя

Объясни различие:

```text
Desk Form → внутренний системный UI
Web Form  → web surface над DocType
```

## Состояние после лабораторной

Оставь Web Form, но Guest creation выключи, если он не нужен для следующего опыта.
