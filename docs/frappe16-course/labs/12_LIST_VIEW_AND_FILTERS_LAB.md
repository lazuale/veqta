# Лабораторная 12. List View и фильтры

## Подготовка данных

Нужно минимум 12–15 Request с разными:

```text
Status
Priority
Responsible
Due Date
```

Если записей мало — создай вручную несколько новых; массовый импорт подробно будет в главе 38.

## Сделай руками

В List View Request:

1. Отфильтруй `Status = Open`.
2. Добавь второй фильтр `Priority = High`.
3. Очисти фильтры.
4. Отсортируй по `Due Date`.
5. Измени набор отображаемых колонок, если UI позволяет.
6. Проверь `In List View` у нескольких DocField.
7. Выбери несколько строк и посмотри доступные bulk actions.

## Эксперимент

Сравни два запроса:

```text
Status = Open AND Priority = High
```

и

```text
Status != Done
```

Посчитай глазами количество строк и проверь, что фильтр действительно меняет выборку.

## Намеренная ошибка

Поставь фильтр, которому не соответствует ни одна запись, например невозможную комбинацию. Убедись, что пустой список — это результат запроса, а не «сломанный DocType».

## Проверка себя

Объясни разницу:

```text
In List View
→ какие поля показывать

Filter
→ какие Documents выбрать

Sort
→ в каком порядке показать выбранные Documents
```

## Состояние после лабораторной

Оставь набор данных; фильтры можно очистить.
