# Лабораторная 02. Desk, Sidebar, Workspace и поиск

## Цель

Научиться находить объекты Frappe без запоминания случайного расположения кнопок.

## Сделай руками

1. Открой `http://learn.localhost:8000` и войди как `Administrator`.
2. Через Awesome Bar последовательно найди:
   - `User`;
   - `DocType`;
   - `Workspace`;
   - `Role`;
   - `System Settings`.
3. Вернись на Desktop/Desk home.
4. Открой любой Workspace из Sidebar.
5. Из списка `User` открой конкретный Document и вернись назад в List View.
6. Открой URL в браузере и посмотри, как route меняется между List и Form.

## Ожидаемый результат

Ты должен различать:

```text
Desk        → весь внутренний интерфейс
Sidebar     → навигация
Workspace   → собранная рабочая область
List View   → список Documents
Form View   → один Document
Awesome Bar → глобальный поиск/переход
```

## Эксперимент

Не пользуйся Sidebar. Найди те же `Role` и `DocType` только через Awesome Bar.

После этого, наоборот, попробуй дойти до них через Workspace/Sidebar.

## Намеренная ошибка

Набери в Awesome Bar заведомо несуществующее имя `Training Unicorn`.

Убедись, что глобальный поиск не создаёт объект автоматически и не гарантирует, что нужный DocType вообще существует.

## Проверка себя

Закрой вкладку и снова открой Desk. Без инструкции найди `DocType` менее чем за 15 секунд.

## Состояние после лабораторной

Данные не изменены.
