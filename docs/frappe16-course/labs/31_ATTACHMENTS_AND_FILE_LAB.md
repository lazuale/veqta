# Лабораторная 31. Attachments и File

## Цель

Увидеть, что вложение во Frappe — это не просто «байты внутри Request», а отдельный `File` Document со связью с владельцем.

## Сделай руками

На одном Request прикрепи:

```text
обычный .txt файл
изображение .png/.jpg
```

Сделай один файл public, другой private, если текущий UI позволяет выбрать режим.

## Проверь

Через Awesome Bar открой `File` и найди обе записи.

Сравни:

```text
file_name
file_url
is_private
attached_to_doctype
attached_to_name
```

Названия полей сверяй с живым DocType v16.

## Эксперимент

Открой URL public-файла в отдельном окне. Затем попробуй аналогично обратиться к private-файлу без подходящей авторизации и сравни поведение.

## Намеренная ошибка

Удалить связь Attachment с Request или удалить File через штатный UI и посмотреть, что происходит в Timeline/Attachments. Не удаляй важные файлы — используй только учебные.

## Проверка себя

Объясни, почему:

```text
Attachment на форме
→ это связь с File Document
```

а не отдельный произвольный столбец в таблице Request.

## Состояние после лабораторной

Оставь минимум один public и один private учебный File.
