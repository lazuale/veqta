# Лабораторная 28. Auto Repeat

## Цель

Проверить штатное периодическое создание документов без собственного scheduler code.

## Подготовка

Для отдельного простого учебного DocType включи `Allow Auto Repeat`. Можно использовать новый `Recurring Note` или другой несабмиттабельный объект, чтобы не смешивать эксперимент с основным Request Workflow.

Поля:

```text
Title  Data
Date   Date
```

## Сделай руками

1. Создай исходный Document.
2. Создай `Auto Repeat` для него.
3. Выбери короткую/понятную учебную периодичность, которую можно проверить, либо выставь ближайшую дату согласно UI.
4. Посмотри поля Auto Repeat и связи с reference document.

## Проверка scheduler

В терминале:

```bash
cd ~/frappe/frappe16-course-bench
bench --site learn.localhost scheduler status
```

Если нужен безопасный ручной запуск scheduler event в dev, используй только документированный bench-механизм текущей версии, а не системный cron вручную.

## Эксперимент

Поменяй частоту/дату следующего запуска и посмотри, как меняется запись Auto Repeat.

## Намеренная ошибка

Отключи Auto Repeat и убедись, что само существование исходного документа не означает автоматическое копирование.

## Проверка себя

Объясни, почему задача «каждый месяц создать копию документа» сначала решается Auto Repeat, а не Server Script + Scheduler.

## Состояние после лабораторной

Auto Repeat можно оставить Disabled после проверки, чтобы он не создавал шум.
