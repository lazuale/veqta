# Лабораторная 23. Assignment и ToDo

## Цель

Увидеть, что назначение — не просто поле `Responsible`, а отдельный механизм Frappe с ToDo.

## Сделай руками

Открой Request и используй штатное действие Assign.

Назначь документ:

```text
student.user@example.test
```

Укажи описание/дату, если интерфейс предлагает.

## Проверь

1. На Request появился assignment indicator.
2. Под назначенным пользователем Request появился в соответствующем рабочем списке/ToDo.
3. Через Awesome Bar открой `ToDo` и найди созданную запись.
4. Сопоставь:

```text
reference_type
reference_name
allocated_to
status
```

## Эксперимент

Назначь тот же Request второму пользователю и сравни количество ToDo.

Затем закрой/удали одно назначение штатным способом.

## Намеренная ошибка

Измени поле `Responsible` и проверь: создаётся ли автоматически ToDo? Если нет — это доказывает, что Link-поле и Assignment subsystem не одно и то же.

## Проверка себя

Объясни разницу:

```text
Responsible Link → данные конкретного DocType
Assignment       → штатный Frappe механизм работы/ToDo
```

## Состояние после лабораторной

Оставь один активный assignment на Request.
