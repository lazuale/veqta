# Лабораторная 29. Timeline и Comments

## Цель

Увидеть Timeline как историю связанных событий вокруг одного Document.

## Сделай руками

На одном Request:

1. добавь обычный Comment;
2. упомяни `student.manager@example.test` через `@`, если mention доступен;
3. измени `Priority`;
4. назначь/сними Assignment;
5. добавь файл или Communication, если уже настроено.

После каждого действия смотри Timeline.

## Проверь системные записи

Через Awesome Bar открой `Comment` и найди запись, связанную с Request.

Посмотри поля reference_doctype/reference_name или эквивалентные связи.

## Эксперимент

Добавь два Comments разными пользователями и сравни автора/время.

## Намеренная ошибка

Не используй Comment как замену полю данных. Запиши важное значение только в комментарии, затем попробуй отфильтровать Request по нему в List View. Станет видно, почему структурированные данные должны жить в полях, а обсуждение — в Timeline.

## Проверка себя

Назови минимум три разных типа событий, которые могут отображаться в Timeline, и объясни, что Comment — лишь один из них.

## Состояние после лабораторной

Оставь тестовые Comments — они пригодятся при изучении истории Document.
