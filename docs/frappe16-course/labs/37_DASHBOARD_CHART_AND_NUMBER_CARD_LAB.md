# Лабораторная 37. Dashboard Chart и Number Card

## Цель

Положить живые показатели Request на Training Workspace.

## Number Card

Создай карточку:

```text
Open Requests
```

которая показывает количество Request с `Status = Open` или другой понятный показатель, поддерживаемый current v16 source.

## Dashboard Chart

Создай chart, например:

```text
Requests by Status
```

или динамику по датам, если данные позволяют.

Добавь Card и Chart в `Training` Workspace.

## Проверка

Создай новый Open Request и обнови Workspace. Число/график должны измениться после обновления данных/кэша согласно механизму источника.

## Эксперимент

Измени Status нескольких Request и сравни показатели до/после.

## Намеренная ошибка

Настрой Card/Chart с фильтром, который не возвращает данные. Убедись, что 0/пустой график может быть корректным результатом, а не ошибкой Framework.

## Проверка себя

Объясни, почему Workspace сам по себе не считает данные: он размещает Number Card/Chart, а источник данных задаётся самими объектами аналитики.

## Состояние после лабораторной

Training Workspace должен содержать рабочие `Open Requests` и `Requests by Status`.
