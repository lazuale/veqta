# Лабораторная 22. Где заканчиваются штатные permissions

## Цель

Научиться диагностировать доступ по слоям, а не менять настройки наугад.

## Сценарий

Используй `Request`, `Training User`, `Training Manager`, `Area`, permission level 1, owner restriction и Share из предыдущих глав.

## Создай контрольную матрицу

Для четырёх Request зафиксируй:

```text
Owner
Area
Shared to Training User?
Internal Cost заполнен?
```

## Проверь под Training User

Для каждого документа отметь:

```text
виден в List?
открывается напрямую?
можно Write?
видно Internal Cost?
```

## Диагностика

Для каждого результата объясни, какой слой повлиял:

```text
Role Permission
If Owner
User Permission
Share
Permission Level
```

## Эксперимент

Измени только один слой — например убери User Permission по Area — и повтори матрицу. Потом верни его.

## Намеренная ошибка

Сделай одновременно несколько изменений permissions и попробуй понять результат. Должно стать очевидно, почему диагностика требует менять один слой за раз. После эксперимента верни исходное состояние.

## Проверка себя

Если Document не виден в List, но открывается по прямой ссылке из-за Share или иной настройки, какие проверки нужно сделать? Не отвечай одной фразой «permissions сломаны» — перечисли слои.

## Состояние после лабораторной

Верни стабильные права, с которыми Training User работает только в North и не видит `Internal Cost`.
