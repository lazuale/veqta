# Лабораторная 38. Data Import / Export

## Цель

Массово выгрузить, изменить и загрузить учебные Request и научиться читать ошибки импорта.

## Экспорт

Через Data Export выгрузи Request с полями:

```text
Subject
Status
Priority
Area
Due Date
Responsible
```

Открой CSV/XLSX и изучи заголовки.

## Импорт новых данных

Скопируй несколько строк, очисти системные ID там, где это требуется для создания новых Documents, измени Subject и импортируй как новые записи.

Проверь их в List View.

## Импорт обновлений

Выгрузи/подготовь файл с существующими `name`, измени `Priority` и импортируй как update. Проверь Version/изменения.

## Намеренная ошибка

Создай отдельную строку с ошибкой:

```text
невалидный Link Area
или
неверный Select Status
или
пустой Mandatory Subject
```

Запусти импорт и прочитай feedback до конкретной строки/поля. Исправь файл и повтори.

## Эксперимент

Добавь значение, похожее на spreadsheet formula, и посмотри современное защитное поведение экспорта/import v16.

## Проверка себя

Объясни различие:

```text
Create new
Update existing
Link validation
Mandatory validation
```

## Состояние после лабораторной

В Request должно быть минимум 40–50 записей для Web/API/analytics упражнений.
