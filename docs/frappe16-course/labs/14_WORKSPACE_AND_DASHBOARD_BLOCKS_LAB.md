# Лабораторная 14. Workspace и dashboard blocks

## Цель

Собрать собственную рабочую область из уже созданных объектов.

## Сделай руками

Создай Workspace:

```text
Training
```

Добавь минимум:

```text
Shortcut → Request
Shortcut → Training Category
Quick List → Request
```

Если Number Card/Chart уже можно построить на текущих данных без лишней настройки — добавь простой счётчик Request. Подробно аналитические карточки разберём в главе 37.

## Ожидаемый результат

После открытия Training Workspace ученик должен сразу получить точки входа в собственные учебные данные.

## Эксперимент

Измени порядок блоков, подписи и ширину/раскладку. Обнови страницу и проверь сохранение.

## Намеренная ошибка

Добавь Shortcut на объект, к которому у будущей ограниченной роли не будет доступа. Позже в блоке permissions вернись к Workspace под другим пользователем и посмотри границу между «ссылка есть» и «permission разрешает открыть объект».

## Проверка себя

Объясни:

```text
Workspace
≠ отдельная база данных
≠ отдельный App
≠ permission layer
```

Это собранная рабочая поверхность над существующими объектами.

## Состояние после лабораторной

Workspace `Training` оставить и использовать до конца курса.
