# Лабораторные Frappe Framework 16

Эта папка — обязательная практическая половина учебника.

Каждой теоретической главе 1–45 соответствует лабораторная с тем же номером.

Формат:

```text
прочитать главу
→ выполнить лабораторную
→ получить ожидаемый результат
→ провести эксперимент
→ увидеть/разобрать ошибку
→ вернуть стенд в указанное состояние
→ только потом идти дальше
```

Основной стенд: [глава 0](../00_LAB_SETUP.md).

Сквозное состояние: [PRACTICE_TRACK.md](../PRACTICE_TRACK.md).
