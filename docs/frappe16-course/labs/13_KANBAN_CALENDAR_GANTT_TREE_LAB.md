# Лабораторная 13. Kanban, Calendar, Gantt и Tree

## Цель

Не просто открыть четыре View, а проверить, какие данные и metadata им нужны.

## Kanban

Для `Request` используй поле `Status`.

Создай Kanban Board и колонки для:

```text
Open
In Progress
Done
```

Перетащи Request между колонками. Затем открой этот Document в Form View и проверь, изменился ли `Status`.

## Calendar

Используй `Due Date`. Подготовь несколько Request на разные даты и открой Calendar View.

Перенеси одну запись на другую дату, если текущий UI это поддерживает, и проверь Document.

## Gantt

Проверь требования Gantt в текущем v16. Если для Request не хватает start/end полей, добавь учебные `Start Date` и `End Date`, настрой соответствующее представление и создай несколько интервалов.

Главная цель — увидеть, что Gantt не может построить временной интервал из одного случайного поля.

## Tree

Открой `Training Category` из лабораторной 09 и поработай с иерархией.

## Намеренная ошибка

Для каждого View убери/очисти одно необходимое поле у тестовой записи и посмотри, как это влияет на представление.

## Проверка себя

Соотнеси:

```text
Kanban   → категориальное поле/колонки
Calendar → дата
Gantt    → временной интервал
Tree     → иерархическая модель DocType
```

## Состояние после лабораторной

Оставь Kanban и тестовые даты: они пригодятся при работе с Workspace и Dashboard.
