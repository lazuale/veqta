# Frappe в VEQTA

В этом разделе собраны материалы VEQTA, связанные непосредственно с Frappe Framework.

## Архитектура

**[Архитектурный стандарт Frappe](frappe-architecture-standard/README.md)** объясняет, как выбирать механизмы Framework и проводить границу между возможностями Frappe и собственным кодом приложения.

Стандарт опирается на официальную документацию, исходный код Frappe и примеры из приложений экосистемы.

## Практика

**[Практикумы Frappe](frappe-training/README.md)** — учебные маршруты VEQTA Learn по разработке на Frappe Framework. Каждый практикум посвящён самостоятельной задаче и ведёт от требования к выбору механизма, реализации и проверке результата.

Архитектурный стандарт можно читать как справочник, а практикумы — проходить последовательно внутри выбранного маршрута.
