# Доступ к данным и отчётность на Frappe

Практикум продолжает [первое приложение](../first-app/README.md) на той же учебной модели `rental_training` и показывает, как выбирать способ чтения и представления данных по смыслу задачи.

Здесь не создаётся новая предметная область. Уже существующих `Equipment`, `Customer`, `Rental` и `Rental Item` достаточно, чтобы пройти путь от стандартного списка до собственных отчётов, увидеть границу permissions и измерить реальную стоимость запросов.

## Что будет построено

Исходная модель остаётся прежней:

```text
Equipment
Customer
Rental
└── Rental Item
```

По ходу практикума появляются:

```text
ограничение Rental Operator своими Rental
        ↓
List View и фильтры
        ↓
Report Builder
        ↓
permission-aware чтение данных
        ↓
Query Report
        ↓
Script Report
        ↓
измерение SQL через Recorder
        ↓
set-based выборка через frappe.qb.get_query
        ↓
автоматические проверки
        ↓
чистая установка
```

Практикум специально различает пользовательское чтение и доверенную системную выборку. `get_list`, `get_all`, загрузка одного `Document`, SQL Query Report и `frappe.qb.get_query` рассматриваются не как уровни «от простого к продвинутому», а как механизмы с разной ответственностью.

Индекс, cache, Prepared Report, background jobs и собственный frontend не добавляются заранее. Они появляются только при отдельной задаче и измеримой необходимости.

## Что нужно знать до начала

Нужно пройти [первое приложение](../first-app/README.md) или иметь эквивалентное понимание:

- Bench / App / Site / Module;
- Standard DocType и Child DocType;
- `Document Controller`;
- Role и DocType Permissions;
- автоматические тесты;
- поставка состояния App и `migrate`.

Практикум [о жизненном цикле Document](../document-lifecycle/README.md) полезен как предыдущая ступень VEQTA Learn, но технически этот маршрут от него не зависит: он продолжает именно `rental_training`.

## Версия

Практикум подготовлен для **Frappe Framework v16**. Версионно-зависимые детали текущего маршрута, включая Report permissions, Query Report и `frappe.qb.get_query`, проверены по документации и исходному коду **v16.33.0**.
