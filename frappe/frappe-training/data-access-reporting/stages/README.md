# Этапы практикума

Практикум продолжается на готовом `rental_training` из маршрута [«Первое приложение»](../../first-app/README.md).

Этапы проходятся последовательно: каждый следующий использует результат предыдущего и добавляет новый механизм только после появления соответствующего требования.

1. **[S00 — исходное состояние и контрольные данные](S00_BASELINE_AND_DATA.md)**  
   Проверить готовый App/Site и подготовить данные нескольких пользователей, на которых будет видна разница permissions, отчётов и запросов.

2. **[S01 — Rental только своего владельца](S01_OWNER_PERMISSIONS.md)**  
   Ограничить `Rental Operator` своими Documents через штатный `If Owner` и доказать результат под разными пользователями.

3. **[S02 — рабочая выборка через List View](S02_LIST_VIEW.md)**  
   Решить обычный реестр Rental стандартным списком, фильтрами и сортировкой без собственного отчёта.

4. **[S03 — простая сводка через Report Builder](S03_REPORT_BUILDER.md)**  
   Добавить `Report` permission тогда, когда он впервые нужен, и построить сохраняемую сводку без Python и SQL.

5. **[S04 — пользовательское и системное чтение](S04_DATA_ACCESS_BOUNDARY.md)**  
   На одних и тех же данных сравнить `get_list`, `get_all` и чтение одного `Document` с явной проверкой `read`.

6. **[S05 — Equipment Rental History](S05_QUERY_REPORT.md)**  
   Построить manager-only Standard Query Report для связанной выборки `Equipment ← Rental Item ← Rental → Customer`.

7. **[S06 — Equipment Utilization](S06_SCRIPT_REPORT.md)**  
   Добавить manager-only Script Report с расчётом занятых календарных дней и процента загрузки.

8. **[S07 — измерить SQL через Recorder](S07_RECORDER.md)**  
   Измерить работающий отчёт, увидеть фактические запросы и зафиксировать N+1 до оптимизации.

9. **[S08 — убрать N+1 через Query Builder](S08_QUERY_BUILDER.md)**  
   Перевести подготовку данных в set-based форму и повторным измерением доказать улучшение без изменения результата.

10. **[S09 — автоматические контракты](S09_AUTOMATED_TESTS.md)**  
    Закрепить собственную permission-модель, аудиторию отчётов и календарный расчёт автоматическими тестами.

11. **[S10 — чистая установка](S10_CLEAN_INSTALL.md)**  
    Установить итоговый `rental_training` на новый Site и проверить границу между состоянием App и рабочими данными Site.

Модель и расчёты описаны в [`../APPLICATION_MODEL.md`](../APPLICATION_MODEL.md), требования — в [`../REQUIREMENTS.md`](../REQUIREMENTS.md), общий маршрут — в [`../ROADMAP.md`](../ROADMAP.md).
