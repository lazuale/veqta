# Практикумы Frappe

VEQTA Learn — практические учебные маршруты по разработке на Frappe Framework.

Каждый практикум посвящён самостоятельной задаче и содержит только те материалы и этапы, которые нужны для её прохождения.

## Первое приложение

**[Первое приложение на Frappe](first-app/README.md)** — последовательный практикум от чистого Bench и Site до собственного App, предметной модели, серверных правил, permissions, автоматических тестов и установки на новый чистый Site.

Практикум рассчитан на первое системное знакомство с разработкой собственного приложения на Frappe Framework.

## Жизненный цикл Document

**[Жизненный цикл Document на Frappe](document-lifecycle/README.md)** — второй практикум о том, как обычный `Document` и предметный `status` превращаются в управляемый `Workflow`, а затем в системный жизненный цикл с `Submit`, `Cancel` и `Amend`.

Практикум использует отдельный учебный `Purchase Request` и предполагает, что базовые границы Bench / App / Site, Standard DocType, permissions и автоматические тесты уже знакомы по первому маршруту.

## Доступ к данным и отчётность

**[Доступ к данным и отчётность на Frappe](data-access-reporting/README.md)** — практикум о том, как безопасно читать, агрегировать и представлять данные уже существующего приложения: от стандартных List View и Report Builder до Query Report, Script Report, Query Builder и измерения SQL через Recorder.

Маршрут продолжает модель `rental_training` из первого практикума и отдельно показывает границу между пользовательской выборкой с permissions и доверенным системным чтением.
