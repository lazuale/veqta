# Практикум Frappe

Практикум знакомит с архитектурой собственного Frappe `App` через разработку небольшого сервиса проката оборудования.

Вместо последовательного обзора возможностей Framework здесь сначала появляется задача, затем выбирается подходящий механизм Frappe и только после этого выполняется реализация.

## Что будет построено

```text
Equipment
Customer
Rental
└── Rental Item
```

По ходу практикума появляются связи между `Document`, предметное состояние, серверные проверки, роли и permissions, автоматические тесты и воспроизводимая установка приложения на чистый `Site`.

## Версия

Практикум подготовлен для **Frappe Framework v16**. Конкретная среда и команды описаны в первом этапе.

## С чего начать

Практические этапы находятся в [`core/`](core/README.md) и проходятся последовательно от `S00` до `S09`.

Дополнительные справочные страницы:

- [`CORE_STAGE_SPECIFICATION.md`](CORE_STAGE_SPECIFICATION.md) — что именно создаётся в учебном приложении;
- [`REQUIREMENTS_MATRIX.md`](REQUIREMENTS_MATRIX.md) — какие требования реализуются по ходу практикума;
- [`PRACTICUM_ROADMAP.md`](PRACTICUM_ROADMAP.md) — маршрут этапов.

Архитектурные объяснения, на которые ссылаются задания, находятся в соседнем [архитектурном стандарте Frappe](../frappe-architecture-standard/README.md).
