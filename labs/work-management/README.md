# Work Management Lab

Work Management — ранний эксперимент VEQTA по моделированию обычной управляемой работы на Frappe Framework.

Эксперимент проверяет, можно ли оставить предметную модель небольшой, а состояния, назначения, историю и рабочий интерфейс получить из штатных механизмов Frappe.

В модели используются два собственных `DocType`:

```text
Work Type
Work Item
```

Поверх них проверяются:

```text
Workflow / Workflow State
Assign To / ToDo
Version / Timeline
Desk
Kanban
```

Это не отдельный продукт и не общая модель VEQTA. Материалы сохранены как пример архитектурного эксперимента.
