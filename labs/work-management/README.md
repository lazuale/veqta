# Work Management Lab

Work Management — исследовательский домен VEQTA Labs для проверки моделей управляемой работы на Frappe Framework.

Здесь не проектируется универсальная система задач и не задаётся общая предметная модель VEQTA. Домен нужен как достаточно простой, но содержательный стенд: у работы есть тип, собственная идентичность и данные, а дальше вокруг неё постепенно появляются операции, история, аналитика и управленческие вопросы.

Исследования идут по общей карте VEQTA Labs:

```text
Data Model
→ Operations
→ History
→ Analytics
→ Management
```

Каждый следующий шаг опирается на фактический результат предыдущего. Механизмы Frappe не добавляются только ради демонстрации возможностей Framework.

## R01 — Data Model

Первое исследование отвечает на вопрос:

> Какую минимальную модель данных нужно сохранить для единицы управляемой работы и где проходит граница между metadata приложения, самостоятельными Documents и системными полями Frappe?

В центре проверки находятся `Work Item` и способ представить его тип: обычным `Select` или ссылкой на самостоятельный `Work Type`.
