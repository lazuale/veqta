# Work Management — модель v0.1

Модель v0.1 используется в эксперименте Work Management для проверки минимального представления управляемой работы на Frappe.

В собственной предметной модели всего два `DocType`:

```text
Work Type
Work Item
```

Остальные части процесса берутся из штатных механизмов Framework и проверяются поверх этой модели.

## Work Type

`Work Type` описывает вид работы.

Поля:

```text
code   Data  required
title  Data  required
```

`code` используется как стабильный идентификатор, `title` — как отображаемое название.

Примеры:

```text
TASK   → обычная задача
CHECK  → работа с отдельным этапом Review
```

## Work Item

`Work Item` — конкретная единица работы.

Поля:

```text
title      Data  required
work_type  Link  required → Work Type
```

Системные поля Frappe (`name`, `owner`, `creation`, `modified` и другие) отдельно не дублируются.

## Состояния

Для состояний эксперимент использует штатный `Workflow` и `Workflow State`.

Проверяются два маршрута:

```text
TASK
New → In Progress → Done

CHECK
New → In Progress → Review → Done
```

Цель проверки — понять, достаточно ли одного Workflow с условиями переходов для разных `Work Type`.

## Назначения

Отдельное поле ответственного в `Work Item` не вводится. Назначение проверяется через штатный `Assign To`, который использует связанные `ToDo`.

## История

Для истории изменений рассматриваются `Version`, Timeline и комментарии Workflow. Эксперимент проверяет, можно ли получить из штатной истории сведения о переходах состояния и использовать их для последующего анализа.

## Интерфейс

Работа с `Work Item` проверяется через стандартный Desk и Kanban. Отдельный пользовательский интерфейс в модели v0.1 не проектируется.

Подробный план проверки находится в [`PROTOTYPE_V0_1.md`](PROTOTYPE_V0_1.md).
